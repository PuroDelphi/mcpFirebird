# MCP Firebird 2.13.0-alpha.2

Prepared October 27, 2026 on `alpha`. **npm publication is pending maintainer
authentication.** The npm `alpha` tag still points to 2.13.0-alpha.1; stable
`latest` remains 2.12.3.

## Fix for issue #47

- Encode markup delimiters at the shared MCP tool display-text boundary, covering
  `describe-batch-tables`, `get-execution-plan`, `echo` and
  `list-available-tools`, including success, partial-batch and failure responses.
- Use JSON Unicode escapes inside string values and keys, retaining exact values
  after `JSON.parse` and in `structuredContent`. Keep existing table-name and SQL
  policies. Plain-text messages/headings use numeric HTML character references;
  use `structuredContent.result.message` for the original echo message.
- Remove caller messages from echo logs and check response size after encoding.
- Preserve existing diagnostics, dates, drivers, dependency versions and output
  schemas. No new setting is required.

See the [English/Spanish compatibility contract](../tool-contract.md#display-text-encoding-47-2130-alpha2).
Decoded and structured values remain untrusted data that clients must render
safely; this is not a general HTML sanitizer or prompt-injection defense.

## Validation

The local `npm run verify:release` gate passed type checking, build, lint error
checks, **1,369 unit tests**, **123 protocol/Node tests with no skips**, and compiled
security-runtime checks. Regression tests cover the report's payload, markup/template/link variants,
JSON escape preservation, nested values/keys, errors and response limits. The
protocol matrix uses controlled drivers over STDIO/HTTP with SDK 1 and SDK 2
legacy/modern clients, including a connection-failure path without Firebird.
No live Firebird server or native-driver integration was used for this display-only
change. The npm archive includes the compiled encoding helper and excludes source
tests and local logs.

The additional `npm audit --omit=dev` check reports **7 affected production
packages (4 high, 3 moderate)** in the existing dependency lockfile:
`@modelcontextprotocol/server`, `@modelcontextprotocol/server-legacy`, `body-parser`,
`ip-address`, `qs`, `undici` and `zod`. Dependencies are unchanged by this issue #47
fix; the release gate does not include npm audit. Review these dependency updates
and rerun validation before resuming publication. This release is not claimed to
have a clean dependency audit.
