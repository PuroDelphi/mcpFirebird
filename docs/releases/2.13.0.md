# MCP Firebird 2.13.0

October 29, 2026. Stable promotion of all changes through `2.13.0-alpha.3`,
including the diagnostics already shipped in 2.12.3. This release advances
`latest` to **2.13.0**; `alpha` remains at 2.13.0-alpha.3.

## Changes since 2.12.3

- **Tool display-text encoding (#47).** Shared tool results and errors encode
  HTML, Markdown and template delimiters. JSON strings use Unicode escapes;
  plain-text echo, headings and custom errors use numeric character references.
  Original values remain available in `structuredContent` and after parsing JSON.
  Echo no longer logs the caller's message.
- **Production dependency fixes.** Resolve the seven affected packages recorded
  in alpha.2: MCP server/server-legacy 2.4.0, body-parser 2.4.0, ip-address 10.7.5,
  qs 6.17.0, undici 6.29.1 and Zod 4.6.7. The coordinated SDK update includes core
  and client 2.4.0, Node adapter 2.1.2 and SDK 1 compatibility client 1.32.2.
- **Additional audit finding.** The stable release audit identified
  [GHSA-rmxm-3fg6-px4f](https://github.com/advisories/GHSA-rmxm-3fg6-px4f), indexed
  after alpha.3. Update locked `@hono/node-server` from 1.19.17 to 2.1.5 within
  the supported MCP dependency ranges. The advisory concerns double-decoding
  static-file paths; the fixed release is 2.1.3 or later.
- **Publication audit.** `npm run audit:production` runs as part of the release
  and prepublication gate. Known production vulnerabilities or unavailable
  registry access fail this check, including optional production dependencies.

## Compatibility

Runtime source and tests match alpha.3. Dependencies retain its updates, with the
additional Hono Node adapter correction above. Firebird driver versions,
SQL/table/role policies, date defaults, query diagnostics and opt-in
security settings are retained. No database migration or new setting is needed.
Node.js 20.19+ remains required.

Text-only clients may display numeric character references literally. Consumers
needing the exact echo message should read `structuredContent.result.message`.
Response-size limits apply after encoding, so markup-heavy replies can reach a
configured limit sooner. Structured or decoded values still need safe rendering
in clients; this is not a general HTML sanitizer or prompt-injection prevention.
See the [display-text contract](../tool-contract.md#display-text-encoding-47-2130-alpha2).

## Install

```sh
npm install -g mcp-firebird@latest
# Or pin this stable release:
npm install -g mcp-firebird@2.13.0
```

For an existing npx launcher, use `mcp-firebird@2.13.0` as the package argument.
Keep database, transport, authentication and security settings, then restart the
MCP process/client.

## Validation scope

- Typecheck, build, lint error checks, **1,369 unit tests**, **124 protocol/Node
  tests without skips**, and compiled security-runtime checks passed.
- **28 focused protocol, output-encoding and diagnostics tests** passed on
  Node.js 20.19.0, including the compressed-body regression.
- **Four clean-package checks** passed: STDIO and HTTP with legacy and modern
  clients, checking the advertised 2.13.0 version, tool catalog, echo encoding
  and SQL denial.
- Both the repository lockfile and a clean production installation of the npm
  archive report **zero known production vulnerabilities**, including optional
  dependencies. This reflects the advisories available at release time.

Development-only tooling findings have a separate scope and are not installed as
production dependencies of this package. The controlled-driver tests do not
claim fresh live Firebird or native-addon integration coverage for this promotion.
The clean package check disables installation scripts, so it does not test native
addon compilation. Earlier live results remain documented in their own releases.
