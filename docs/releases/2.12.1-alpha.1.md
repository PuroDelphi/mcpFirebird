# MCP Firebird 2.12.1-alpha.1

October 14, 2026. This alpha includes the fixes from issue #44 and the adjusted contribution from PR #43, on top of stable 2.12.0.

## SQL policy compatibility (#44)

The conservative query policy previously treated any word before `(` as a function candidate. This rejected valid expressions such as `ORDER BY (ID)`, `LIKE ('I%')`, `STARTING WITH ('IRL')` and `SIMILAR TO ('IRL%')` when `allowUnsafeQueries=false` was configured.

SQL parenthesis grammar now has its own contextual classification, separate from the builtin-function list. The shared query boundary recognizes grouped clauses/predicates, comparison FROM separators, window clauses and the ranking/navigational window-function family. Those window-function names require an analytic call with OVER; a standalone routine with the same name on an older server is not exempted. All nested routines and relations continue to be checked. Quoted/package-qualified routines and unknown functions are not builtin exemptions; table/catalog permissions, row filtering, masking and scoped-query limits remain enforced.

No policy change or new flag is required. Window functions still depend on the Firebird server version; Firebird 2.5 does not support them. The policy remains conservative rather than a complete Firebird SQL parser. See the [English security guide](../security.md) or [Spanish guide](../security.es.md).

## BLOBs, dates, statistics and prompts (#43)

Credit to @sudeposutemizligi for the original contribution. Pure-JS SQL executes once in an explicit transaction; BLOBs are read before that transaction closes. Existing authorized writes and audit inserts keep their transaction mode. Commit failures propagate, and pending callbacks/cleanup cannot release a busy connection after a fixed timer.

Pure-JS database Date columns retain their stored wall-clock fields as `YYYY-MM-DD HH:mm:ss.SSS`, without UTC conversion. Consumers interpreting previous values as UTC should adjust their parsing; precision is limited to JavaScript milliseconds. Native-adapter date behavior and generic Buffer/Date serialization remain unchanged. Statistics use a Firebird 2.5-compatible count alias. Missing/placeholder prompt arguments receive usable defaults. See [compatibility details](../blob-date-compatibility.md).

## Install and test

```sh
npm install -g mcp-firebird@2.12.1-alpha.1
```

For an existing `npx` MCP launcher, select `mcp-firebird@2.12.1-alpha.1` (or `mcp-firebird@alpha`) in its arguments. Preserve the existing transport, connection and policy configuration, and restart the MCP process. Stable `latest` remains 2.12.0.

## Validation

The added 519-case syntax/security suite checks valid grouping, the window-function family, formatting/comment variants and blocked nested routines/catalog access. The disposable live Firebird script additionally compares grouped/predicate query results with direct database results and retains the BLOB, statistics, audit, write and event regressions. Live window execution requires a Firebird 3+ test service; local Firebird 2.5 coverage does not claim those runtime features or the reporter's WIN1254 configuration.

On October 14, 2026, `npm run verify:release` passed type checking, build, lint, 1,273 unit tests, 92 protocol/Node tests and security-runtime checks. The live smoke then passed on Firebird 2.5.9 with the pure-JavaScript driver, including 14 grouped/predicate result comparisons, nested-denial checks and the previous BLOB/statistics/write/audit/event regressions. Its UUID-named database and audit file were removed afterwards.
