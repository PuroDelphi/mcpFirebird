# MCP Firebird 2.13.0-alpha.3

October 27, 2026. Updates the npm `alpha` channel; stable `latest` remains 2.12.3.

## Dependency remediation

Resolves the seven affected production packages documented in alpha.2 (four high,
three moderate). Versions in the repository lockfile:

| Package | Before | After |
| --- | --- | --- |
| `@modelcontextprotocol/server` | 2.2.0 | 2.4.0 |
| `@modelcontextprotocol/server-legacy` | 2.2.0 | 2.4.0 |
| `body-parser` | 2.3.0 | 2.4.0 |
| `ip-address` | 10.7.2 | 10.7.5 |
| `qs` | 6.16.0 | 6.17.0 |
| `undici` | 6.29.0 | 6.29.1 |
| `zod` | 4.6.5 | 4.6.7 |

The direct MCP server/server-legacy and Zod dependency ranges now start at the
corrected versions. The coordinated MCP update also moves the Node adapter to
2.1.2 and core/client to 2.4.0; the SDK 1 test client moves to 1.32.2. The four
indirect production updates remain within their parents' supported ranges.
Firebird drivers, SQL policies, date defaults and output schemas are unchanged.
The issue #47 display-text fix from alpha.2 is retained.

The [MCP 2.4 release notes](https://github.com/modelcontextprotocol/typescript-sdk/releases/tag/v2.4.0)
describe upstream compatibility details. Our transport/output-contract tests
exercise legacy and modern clients with the updated SDKs. The updates also
address the [body-parser compressed-body advisory](https://github.com/advisories/GHSA-27r3-jxmh-p828)
and [Zod validation advisory](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5).

## Validation and audit scope

- Typecheck, build, lint error checks, **1,369 unit tests**, **124 protocol/Node
  tests without skips**, and compiled security-runtime checks passed.
- `npm audit --omit=dev` reports **zero known production vulnerabilities**,
  including optional dependencies. The new `audit:production` command is part of
  `verify:release` and `prepublishOnly`; it requires registry access and prevents
  publication when that audit fails.
- The production HTTP regression accepts valid gzip requests, rejects a body with
  trailing compressed-stream garbage, and verifies that the server remains
  available afterward. Focused protocol, output-encoding and diagnostics checks
  also passed on the minimum supported Node.js 20.19.0 (27 existing cases plus
  the new gzip regression).
- A clean installation of the npm archive, without repository dependency links,
  reports zero production audit findings and passes STDIO/HTTP legacy/modern
  catalog, version, echo-encoding and SQL-denial checks. Installation scripts
  were disabled for this packaging check; native-addon compilation was not tested.
- The full development checkout still reports 19 affected packages (seven low,
  two moderate, seven high, three critical), confined to development tooling and
  its dependencies. These are not installed as this package's production
  dependencies. Zero production findings is not a claim of a clean development
  audit or protection against future advisories.
- No live Firebird service or native-addon integration was used for this
  dependency update. The existing controlled-driver tests remain in place.

## Install

```sh
npm install -g mcp-firebird@2.13.0-alpha.3
# Or: npm install -g mcp-firebird@alpha
```

Node.js 20.19+ is still required. Restart the MCP/client with the existing
connection, transport and security configuration; no new setting is needed.
